# LLM Feature Test Log — Not Executed by Default
===================================================

The LLM-powered sentiment feature extraction via Anthropic API (claude-haiku-4-5-20251001) is functional but requires a private API key. 

For security reasons, the `ANTHROPIC_API_KEY` is not bundled with this submission. By default, the script gracefully falls back to a neutral score (0.0000) when the API key is not present.

**How to Test the LLM Features:**
1. Open `configs/.env.example`
2. Save it as `configs/.env`
3. Replace `your_anthropic_api_key_here` with a valid Anthropic API key.
4. Re-run `run_all_tests.m`. The pipeline will automatically detect the key, perform API calls, and generate real sentiment scores.
